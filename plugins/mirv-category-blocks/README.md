# MIRV Category Blocks

Плагин WordPress для красивого вывода нескольких блоков записей по выбранным рубрикам.

## Что умеет

- Настройка через `Настройки → MIRV Blocks`.
- Добавление нескольких рубрик для вывода на главной.
- Для каждой рубрики: заголовок, количество записей, включить/выключить, показывать/скрывать дату публикации.
- Глобальный выбор: последние или случайные записи.
- Глобальный выбор: карточки в строку или список по одной карточке.
- Шорткод: `[mirv_category_blocks]`.

## Установка

1. Скопируй папку `mirv-category-blocks` в `wp-content/plugins/`.
2. Активируй плагин в админке WordPress.
3. Открой `Настройки → MIRV Blocks`.
4. Добавь нужные рубрики.
5. На странице вставь блок `Шорткод` с текстом:

```text
[mirv_category_blocks]
```

## Переопределение настроек в шорткоде

```text
[mirv_category_blocks mode="random" layout="cards" columns="3"]
```

Параметры:

- `mode="latest"` или `mode="random"`
- `layout="cards"` или `layout="list"`
- `columns="1"`, `columns="2"`, `columns="3"`, `columns="4"`


## Последние публикации

Для главной страницы доступен шорткод:

`[mirv_latest_posts count="4"]`

Он показывает самую свежую запись крупно и следующие записи компактным списком.


## Иерархия рубрик (0.4.1)

Список рубрик в настройках показывается деревом WordPress.

Для каждого блока есть опция **«Родительская и все вложенные»**:
- включена — записи выбираются из выбранной рубрики и всех её потомков;
- выключена — только записи, назначенные непосредственно выбранной рубрике.

Для старых сохранённых блоков опция считается включённой, чтобы обновление сохраняло прежнее поведение.


## Блок «Новое» (0.4.2)

`[mirv_latest_posts]` теперь управляется из **Настройки → MIRV Blocks**:

- количество публикаций (2–6);
- рубрика-источник;
- включение всех вложенных рубрик;
- необязательная подпись справа от заголовка.

На Mirv.Top источник по умолчанию — рубрика **«Блог»** (ID 1).
Это позволяет отдельно публиковать рассказы/стихи и анонсировать их обычной блоговой записью.

Параметры `count` и `category` можно временно переопределить в самом шорткоде,
но на главной рекомендуется использовать просто `[mirv_latest_posts]`.


## Дата публикации по рубрикам (0.4.3)

Для каждого блока в разделе **«Рубрики на главной»** появилась отдельная опция
**«Показывать дату публикации»**.

Теперь дату можно включить, например, только у «Около ПК», оставив её скрытой у рассказов или других блоков.
Старые сохранённые блоки до первого сохранения наследуют прежнюю глобальную настройку даты,
поэтому обновление не меняет внешний вид главной само по себе.
